# 分发

用户怎么把程序装到机器上,又怎么卸掉。

## 能单二进制就单二进制

如果你的语言不原生编译成二进制,看看有没有 PyInstaller 之类的工具。单二进制是最干净的安装故事:下载、`chmod +x`、运行。

## 不能的话,用平台原生包管理器

实在做不到单二进制,就用平台原生包管理器(Homebrew、apt、dnf、winget、scoop 等)。别把文件撒得到处都是又难以清理。

## 轻拿轻放

- 除非用户明确同意,否则不要写 `~/.bashrc`、`~/.zshrc`、`/etc/paths` 等。
- 不要在没同意的情况下装守护进程、launchd 服务或 cron 任务。
- 不要在非临时目录留下临时文件、缓存或 socket。

## 易卸载

如果需要卸载说明,放在安装说明的末尾 —— 用户想卸载的最常见时机就是刚装完的时候。

## 例外

- 语言专属工具(linter、formatter、test runner)可以假设用户已安装该语言解释器。这些工具用 `pip install` 或 `npm install -g` 没问题。
- 构建时使用的开发工具(`Makefile` 中下载二进制的步骤)可以更激进地放置位置,因为开发者已经在跑安装步骤。
